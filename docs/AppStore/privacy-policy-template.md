# GlyphEvolver privacy policy — draft for owner review

Effective date and publisher contact must be supplied before hosting.

GlyphEvolver's implemented search features operate locally without an account or developer-operated backend. The app stores run settings, lineage metadata, ratings and preference parameters on the device. Accepted glyph data will also be stored locally once native generation is implemented and verified.

The app may use explicit ratings to improve proposed combinations. Learning data and model parameters are not automatically transmitted to a server. Interaction signals are retained separately; the current learning model uses only explicit ratings. Cloud synchronization is not configured.

You may initiate an export of lightweight metadata to a location you choose. The lightweight export does not include native glyph binary data. Any external destination or device backup may be subject to its provider's policies.

Before publishing, replace development language with verified final behavior, document the completed run-deletion controls, describe Apple's system generation services accurately, and add a working privacy contact. Do not host this draft as the final policy.
